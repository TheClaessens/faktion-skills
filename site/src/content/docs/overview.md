These pages are the documentation for **Faktion PM skills** — ticket-writing
skills that run in Claude. A product manager brings a request; the skills
settle the scope, draft against the house bar, and push to JIRA only after
approval.

The [homepage](../) sits outside this documentation theme. It is the
orientation surface. These pages are the reference around it.

## What is here today

This overview exists so the documentation navigation works. Later pages will
cover install (Cowork first), how the pipeline runs, the house ticket bar,
the catalogue of functional-vagueness smells, and explicit guarantees about
what the tool will not do.

## Who it is for

Faktion PMs who write stories and bugs. If that is not your job, you can stop
here.
