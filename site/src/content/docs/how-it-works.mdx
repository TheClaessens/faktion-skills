A request travels from the front door through a grill and into a draft, then
to JIRA only after you approve it. The walkthrough of that pipeline lands on
this page later. The table below is already generated: every skill the
manifest lists, with the description and invocation flag from its own
frontmatter. Each name opens a short page for that skill; those pages are
not in the sidebar.
