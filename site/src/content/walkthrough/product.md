# Briefroom

A meeting-notes tool for consultancies. Fictional. No real project key, client, or internal feature.

A consultant records a client workshop. Briefroom keeps that recording as a **transcription session**: the audio, the transcript, and the session detail screen that holds them. **Notes** the consultant writes up from the workshop live on a **project**. A project has a session list and a notes list.

The request used in the walkthrough is the one the README already uses as the example: *create a way to delete a transcription session*. It sounds finished. It is not. Soft delete and hard delete are different products, and a developer who picked either one could honestly say they followed the sentence.
